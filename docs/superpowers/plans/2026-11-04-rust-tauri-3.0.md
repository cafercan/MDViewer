# MD Flow Viewer 3.0 — Rust/Tauri Geçişi Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Python/Flask/pywebview kabuğunu Rust + Tauri 2 ile değiştirmek; arayüz (`public/`) ve kullanıcıya görünen davranış aynı kalır, kurulum boyutu ~15 MB'tan ~4 MB'a iner.

**Architecture:** aicstation düzeni: Cargo workspace = `core` (Tauri'siz, saf mantık, birim testli) + `src-tauri` (pencere, IPC komutları, `mdasset` özel protokolü, dosya izleyici). Yerel HTTP sunucusu, port ve oturum anahtarı kalkar: arayüz Tauri'nin gömülü varlık sunucusundan gelir, `/api/*` çağrıları `invoke`'a, SSE `notify` + Tauri olayına, `/api/asset` `mdasset://` protokolüne dönüşür. `public/` derleme adımı olmadan `frontendDist` olarak kullanılır (`withGlobalTauri`).

**Tech Stack:** Rust 1.99 (edition 2021), Tauri 2, tauri-plugin-dialog 2, notify 6, serde/serde_json, opener (ya da tauri-plugin-opener 2), tempfile (test). Paketleme: Inno Setup 6 (Windows, mevcut betik), dpkg-deb (Linux, mevcut betik), hdiutil (macOS).

**Spec:** Bu oturumdaki karar özeti (aşağıda "Kararlar"); davranış kaynağı mevcut `app/server.py`, `app/main.py` ve `tests/*.py`. Port boyunca Python kodu referans spesifikasyondur; silme işi Task 10'da.

## Global Constraints

- Ayar dosyası yolu ve biçimi değişmez: Windows `%APPDATA%\MDFlowViewer\settings.json`, diğerleri `$XDG_CONFIG_HOME` ya da `~/.config/MDFlowViewer/settings.json`; UTF-8, 2 boşluk girintili JSON, bilinmeyen anahtarlar korunur.
- Kabuk anahtarları aynen: `lastDir`, `recentFiles`, `recentFolders`, `vaultPath`. `RECENT_LIMIT = 10`.
- Windows: Inno `AppId={{9E7231B5-C614-4AAA-B5EA-B73031BECD16}`, kurulu exe adı `MDFlowViewer.exe`, çıktı `dist\MDViewer-v<sürüm>.exe`.
- macOS: `MD Flow Viewer.app`, bundle id `com.cafercan.mdflowviewer`, çıktı `dist/MDViewer-v<sürüm>-macos-arm64.dmg`, `LSMinimumSystemVersion` 11.0, CFBundleDocumentTypes mevcut betikteki JSON'la aynı.
- Linux: paket `mdflowviewer`, ikili `/usr/bin/mdflowviewer`, WM class `mdflowviewer`, çıktı `dist/mdflowviewer_<sürüm>_amd64.deb`, `Architecture: amd64`.
- Pencere: başlık `MD Flow Viewer`, 1280×860, en küçük 820×560, metin seçilebilir.
- Kullanıcıya dönen Türkçe hata/karşılama metinleri `app/server.py`'dekiyle birebir aynı (ör. `Erişim reddedildi: çalışma klasörü dışında.`, `Dosya bulunamadı: <yol>`, `WELCOME_MD`).
- IPC komut adları JsApi metot adlarıyla aynı (snake_case); dönüş JSON şekilleri Python'dakiyle aynı alan adlarını taşır (`success`, `error`, `root`, `vault`, `locked`, `canUp`, `dirs`, `files`, `type`, `note` …).
- Yol karşılaştırma **sözcüksel** (lexical) normalleştirmeyle yapılır, `canonicalize` kullanılmaz (`\\?\` öneki ve symlink çözme Python davranışından sapar); Windows'ta büyük/küçük harf duyarsız.
- Her `public/*.js` değişikliği mevcut Node testleriyle (`node --test tests/*.test.js`) geçmeli.
- Belge metni arayüze her zaman `\n` satır sonlu ve BOM'suz gider (Python'un universal-newline okumasıyla aynı); diske yazarken dosyanın mevcut biçimi (CRLF/LF, BOM var/yok) geri uygulanır. Yeni dosya: Windows'ta CRLF, diğerlerinde LF, BOM yok (2.x'in Windows'taki fiili davranışı).

## Review Focus

1. **Pencere dışarı gezinmesi:** belgedeki bir bağlantı ya da sürüklenen URL webview'i uzak bir sayfaya götürmemeli; uygulama kökü dışı her gezinme engellenir, http(s)/mailto sistem tarayıcısına gider. → Task 8 `is_app_url` testi.
2. **Atomik kaydetme (temp + rename) yapan editörler:** VS Code/Obsidian dosyayı yeniden adlandırarak yazar; dosya düzeyinde izleyici bundan sonra susar. Kullanıcı canlı yenilemenin sürmesini bekler. → Task 7 `rename_replace_still_notifies`.
3. **UTF-8 olmayan dosya:** açmak uygulamayı çökertmemeli, Türkçe hata mesajı göstermeli. → Task 5 `content_non_utf8_returns_error`.
4. **Windows yol farkları:** `c:\docs` ile `C:\Docs` aynı kök sayılmalı; başka sürücü ve `..` ile kökten kaçış reddedilmeli. → Task 2 `is_under_*` testleri.
5. **Salt okunur ya da başka süreçte kilitli dosyaya kayıt** (atomik kayıt eklendiği için yeni risk): kayıt hata mesajıyla başarısız olmalı, asıl dosya ve klasörde geçici dosya artığı kalmamalı. → Task 2b `atomic_write_readonly_target_fails_cleanly`.
6. **Türkçe karakter/boşluk içeren görsel yolları** (`görseller/şema 1.png`): `mdasset` URL'si kodlanıp çözülünce aynı dosyayı vermeli. → Task 6 `asset_unicode_path_roundtrip`.
